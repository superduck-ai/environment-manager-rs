# 第三方许可

图片兼容模块的 JPEG 表、正逆 DCT、JPEG 扫描/色彩转换和 PNG/DEFLATE 决策源自 Go 1.26.8 标准库，并转换为 Rust 实现。Catmull-Rom 缩放的计算规则参考 golang.org/x/image v0.16.0。运行和构建无需 Go。
